# The SHARD PARTITION of the pull-request functional suite (.github/workflows/pr-ci.yml).
#
# WHY IT EXISTS, measured on the hosted 4-vCPU runner (run 35293935807, 2026-09-18). The
# suite ran in ONE job and took 77 min 8 s of step and 78 min 55 s of job over 280
# packages. Two earlier runs did not finish: the 60-minute step ceiling cut them twice.
# The two packages that later hit the 45-minute Go clock are split by test name as well as
# by package, so no single test binary has to finish the whole suite.
#
# SHARD NAMES AND PACKAGE OWNERSHIP ARE DECLARED; TEST ASSIGNMENT IS GENERATED. Every
# Test/Fuzz/Example of a name-split package is assigned exactly once by SHA-256 of the package
# domain and full function name. Adding a test needs no edit here and moves no existing test.
# The generated expression is fully anchored, so prefix overlap cannot run a test twice.
#
# FORMAT — one record per line, fields separated by whitespace, `#` starts a comment.
#
#   shard <name>                 declares a shard. THE ORDER IS THE MATRIX ORDER.
#   pkg   <shard> <pattern>      an import-path pattern that shard owns.
#                                `<path>/...` is the subtree; anything else is exact.
#   group <shard> <package> <name>
#                                one generated test-name group of ONE package. All groups of
#                                that package share the deterministic assignment in record order.
#   leg   <shard> <task>         a Taskfile leg that shard runs after its packages.
#   optional <pattern>           this pattern MAY match nothing, because the module it
#                                names is not published in every tree. Everywhere else a
#                                pattern that matches nothing is stale and is a finding.
#   go-timeout-minutes <n>       `go test -timeout` inside a shard.
#   step-ceiling-minutes <n>     the workflow step ceiling. Must exceed the go timeout.
#   job-ceiling-minutes <n>      the workflow job ceiling.
#
# PACKAGE ASSIGNMENT RULE: THE LONGEST MATCHING PATTERN WINS. It lets a broad pattern and a
# surgical one live side by side without either listing the other's packages. Two patterns
# of the SAME length claiming one package are a finding, not a tie to break quietly. A package
# with `group` records is outside this rule: its groups own it and no pattern may send it whole.
#
# Test count is not a duration guarantee. The shard counts and clocks below come from hosted
# measurements; if a generated shard exceeds its clock, change the shard count from measured
# durations rather than restoring a hand-written family list.

# THE PULL-REQUEST MATRIX IS NOT DERIVED FROM THIS FILE, IT IS COMPARED WITH IT. The reader has a
# `matrix` subcommand and the pull-request and mainline workflows declare their lists: deriving
# them would need a setup job, and a job costs a runner on every pull request. What makes the two
# agree is scripts/check-pr-suite-shards.sh, which compares them INCLUDING ORDER and refuses on any
# difference — so adding a shard means editing this file and both workflows, and forgetting either
# one is a red and not a drift. The scheduled main-suite is the exception: it derives the matrix of
# its cmd/olivares root-package job from these name groups with `partition`, so a group
# change here reaches that job without editing a list, and the gate still pins the other two.
#
# THE BATTERIES' CLOCKS (the regression, decided 2026-10-18). The numbers below are the BLOCKING
# path's: pr-ci.yml, mainline-ci.yml and candidate-shards.yml, pinned to them by
# scripts/check-pr-suite-shards.sh. The scheduled batteries (merge-gate-check.yml) run the same
# shards off the merge path, where a clock detects a hang and does not gate speed, so they run
# under these clocks TIMES ONE FACTOR, OLIVARES_SHARD_CLOCK_FACTOR=2: 90 minutes of Go, 110 of
# step, 205 of job. This is not a second set of numbers. Go's 45m timeout stays PER TEST BINARY
# and yields a goroutine dump before the 55m step ceiling cancels the leg.
go-timeout-minutes 45
step-ceiling-minutes 55
job-ceiling-minutes 65
