# olivares (Go client)

First-party Go client for the Olivares AI control plane REST API (`/v1`).
Standard library only. Apache-2.0.

```go
import olivares "github.com/olivaresai/olivares/clients/go"

c, err := olivares.New("https://olivares.example:8443", "olvk_...")
info, err := c.GetV1ServerInfo(ctx)
for agent, err := range c.ListPages(ctx, "/v1/agents") { ... }
```

See `doc.go` for the layering (hand-written core + generated operation layer)
and <https://olivares.ai/docs> for the governing
stability policy. The operation layer is regenerated by `task sdk:generate`.
