description: >-
  Stand up the control plane on a disconnected network: carry a verified
  artifact across the gap (static binary, or the signed bundle for a cluster),
  verify it offline, install, and reach first value with zero egress.
sidebar:
  order: 4
---

Air-gapped installation requires Enterprise. The deployment scripts and full installation guide are supplied with the Enterprise distribution. Community and Business can verify an offline update bundle without installing it:

```bash
olivares upgrade --bundle ./release-bundle --check
```

Offline bundle installation is refused before the license or bundle is read. For a connected Community installation, see [the single-node tutorial](/tutorials/getting-started/single-node/).
