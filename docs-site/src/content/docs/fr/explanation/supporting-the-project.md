Olivares AI est **open core**, et cette séparation n'est pas un procédé marketing :
la plateforme de gouvernance complète est sous AGPL-3.0-only et le cœur communautaire
est la partie destinée à être la plus utilisée. Consultez [Open core et
licences](/fr/explanation/open-core-and-licensing/) pour savoir ce qui se trouve dans
chaque build.

Cette organisation doit être financée par quelque chose ; il vaut donc la peine de
dire clairement ce qui la finance.

## Ce qui finance le travail aujourd'hui

L'**abonnement commercial** de la ligne additive `enterprise/`. Si votre organisation
a besoin de ces modules, leur achat finance le cœur AGPL que tous les autres exécutent
gratuitement — y compris les personnes qui ne paient jamais rien.

Il n'existe pas de programme de dons distinct en fonctionnement, et aucune page ici
n'y renvoie. Lorsque cela changera, cette page le dira ; jusque-là, elle ne propose
pas de voie qui ne puisse pas être suivie.

## Moyens de soutenir le projet sans rien dépenser

Ce sont des gestes ordinaires, et ils sont réellement utiles pour un projet pré-1.0
destiné à des ingénieurs qui exploitent leurs propres serveurs :

- **Utilisez-le et signalez ce qui ne fonctionne pas.** Un rapport de défaut avec la
  version, la commande et la sortie vaut davantage qu'une étoile. Le produit est en
  bêta et l'indique.
- **Corrigez la documentation.** Si une page vous a indiqué quelque chose qui s'est
  révélé faux sur votre machine, c'est un défaut de documentation et nous voulons en
  être informés.
- **Contribuez du code sous AGPL.** Le cœur est ouvert ; la voie de contribution est
  celle habituelle du dépôt.

## Ce que le mécénat n'achète pas

Si un programme de dons ouvre plus tard, il n'achètera ni support prioritaire, ni
place dans la file, ni influence sur ce qui est construit. Les engagements de support
relèvent de l'abonnement commercial, où ils sont écrits et peuvent être opposés.
Séparer ces deux choses est l'objectif : un projet où payer discrètement vous fait
remonter dans la file des tickets est un projet où la majorité qui ne paie pas est de
seconde classe, alors que le cœur communautaire est censé être la partie la plus
utilisée.
