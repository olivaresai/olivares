---
title: "Démarrer sur un site air-gapped"
description: >-
  Mettez en place le control plane sur un réseau déconnecté : transportez un
  artefact vérifié à travers la coupure (binaire statique, ou le bundle signé pour
  un cluster), vérifiez-le hors ligne, installez, et atteignez la première valeur
  avec zéro sortie réseau.
sidebar:
  order: 4
---

L’installation dans un environnement isolé nécessite Enterprise. Les scripts de déploiement et le guide complet sont fournis avec la distribution Enterprise. Community et Business peuvent vérifier un paquet de mise à jour sans l’installer :

```bash
olivares upgrade --bundle ./release-bundle --check
```
