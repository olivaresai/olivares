---
title: Scanned documents (OCR)
description: Optional local Unlimited-OCR 2 backend for the Documents module.
---

Off by default. Enable Scanned documents (OCR) in Settings > Modules after provisioning the model and setting the administrator’s `document_ocr` endpoint. Scanned pages and images use the Documents converter; ordinary document conversion remains available with OCR off.

[Configuration, privacy rules and limits](./../documents/#scanned-pages-and-ocr).
