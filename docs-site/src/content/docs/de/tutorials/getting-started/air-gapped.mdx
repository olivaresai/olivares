description: >-
  Bringen Sie die Control Plane in einem getrennten Netzwerk zum Laufen: tragen
  Sie ein verifiziertes Artefakt über die Lücke (statisches Binary oder das
  signierte Bundle für einen Cluster), verifizieren Sie es offline, installieren
  Sie es und erreichen Sie den ersten Mehrwert mit null Egress.

  order: 4
---

Die Installation in einer abgeschotteten Umgebung erfordert Enterprise. Die Deployment-Skripte und die vollständige Installationsanleitung gehören zur Enterprise-Distribution. Community und Business können ein Offline-Update-Bundle prüfen, ohne es zu installieren:

```bash
olivares upgrade --bundle ./release-bundle --check
```
