エアギャップ環境へのインストールには Enterprise が必要です。デプロイスクリプトと完全なインストールガイドは Enterprise ディストリビューションに含まれます。Community と Business では、オフライン更新バンドルをインストールせずに検証できます。

```bash
olivares upgrade --bundle ./release-bundle --check
```
