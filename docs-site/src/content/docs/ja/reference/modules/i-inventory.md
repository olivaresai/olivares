モジュール I は**エステートのカタログ**である。存在するあらゆるもの(エージェント、
セッション、Claude Code インスタンス、MCP サーバー、スキル、ツール、リソース、モデル、
プロバイダー、非人間 ID)の、受動的でバス駆動のインベントリである。プローブによってではなく
*リッスン*することで発見し、ペイロードは決して記録せず、関係性、識別子、生存性のみを
記録する。本ページは、カタログが保持するもの、そして意図的に保持しないものについての
リファレンスである。

## 何を具現化するか

コネクターはエンティティではなく**観測**を発行する。コネクターは正規化された
[`edge.observed`](/ja/reference/events/) と [`cost.sampled`](/ja/reference/events/) のファクトを
イベントバスへ publish するが、それらが含意するエンティティそのものが送信されることは
決してない。モジュール I は、各観測が指し示すコアエンティティを、その自然な参照から
**具現化**する。すなわち、起点となる `session`/`agent`/`identity`、MCP サーバー、ツール、
リソース、スキル、そしてコストサンプルからプロバイダーとモデル(**価格情報なし**で発見される。
価格情報は FinOps が所有する)である。具現化は at-least-once 配信下で**冪等**である。
自然キーに対する find-or-create を行うため、同じ観測を 2 回見ても決してエンティティが
重複することはない。

## コントラクトとエンティティ

本モジュールは自身のエンティティを 1 つ登録する。`inventory.catalog_entry` は、
具現化された各コアエンティティに付随する発見オーバーレイである。それが記録するのは
*どのように*見つかったかであり、*何を*したかではない。すなわち、シグナルソースの一覧、
それが観測されたホスト、初回観測・最終観測のタイムスタンプ、発生回数、そして `active` または
`stale` という生存性 `status` である。定期的な**陳腐化スイープ**は、設定されたウィンドウ内で
観測されなかったエントリを `stale` とマークし、再出現した瞬間に `active` へ戻す。スイープは
モジュールが実際に観測したテナントに対してのみ実行される(テナントを列挙することはできず、
また列挙しない)。読み取りサーフェスは小さく読み取り専用である。すなわち、種別とソース別の
件数を示す `summary`、種別とステータスでフィルタ可能なページネーション付きの `entities` 一覧、
そして単一エンティティの詳細ビューである。すべての読み取りはテナントスコープの名前空間付き
読み取りパーミッションを必要とする(最下位の閲覧者ティアで十分)。取り込みは高頻度であり、
書き込みごとに監査されることはない。完全な形状は
[イベントバスリファレンス](/ja/reference/events/) および本製品の型付きインターフェイスに存在する。

## 何を消費し何を生成するか

モジュール I は純粋な**コンシューマー**である。`edge.observed`、`cost.sampled`、
`finding.reported` をサブスクライブし、自身のカタログオーバーレイと、そこから導出する
コアエンティティのみを書き込む。自身のイベントは一切発行せず、アクチュエーション
サーフェスも公開しない。発見は本質的に observe-and-catalog である。本モジュールが
永続化する参照は、コネクターから**既にレダクトされた状態**で到着する。モジュールは
それらをそのまま保存し、自身の生の詳細を一切付加しない。したがって minimal-data 特性は
ワイヤーの特性であり、エンドツーエンドで保たれる。

:::caution[誠実な限界]
- **インベントリはアクセスグラフを所有しない。** 決定 A(2026-06-03)の時点で、
  モジュール III(アクセスマップ)が read/write の `AccessEdge` の**唯一の書き手**であり、
  トポロジーおよび Permitted-vs-Observed 差分の唯一の所有者である。インベントリは
  エッジが指し示す*エンティティ*を発見しカタログ化するが、エッジ自体はもはや記録せず、
  トポロジールートも提供しない。グラフはモジュール III が起動時に配線されている場合にのみ
  ポピュレートされる。
- **発見はシグナルの分しか完全になりえない。** あるエンティティは、いずれかのコネクターが
  それを観測した場合にのみカタログに存在する。カバレッジが部分的な箇所では、カタログに
  存在しないことはエステートに存在しないことの証明には**ならない**。
- **生存性は陳腐化であり健全性ではない。** `stale` は「最近観測されていない」ことを意味する
  だけであり、それ以上ではない。セッションの沈黙は正常であり、正式な健全性/SLA は
  モジュール XXII に属する。スイープがコアエンティティ自身のライフサイクルを変更することは
  決してない。
- **捏造された詳細はない。** 本モジュールは識別子、関係性、生存性カウンターのみを保存する。
  ペイロード、シークレット、PII、コマンド、クエリ、URL は決して保存しない。
:::
