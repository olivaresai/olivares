モジュール XXI は **Web 層**(層 4)のリーダーシップ表面である。estate を高水準で
読み取るもの — 支出、使用量、リスク態勢、コンプライアンスカバレッジ、信頼性 — で、
モジュールごとの技術 UI と並んで存在する。それは**集約して提示する。決して再計算
しない**(モジュールがすべての数値を所有する)。そして要約するビューと同じテナント
スコープと RBAC を継承する。

## 概要

このモジュールは 2 つの読み取り専用の表面で構成される:

- **エグゼクティブダッシュボード**(`/dashboards`) — モジュールをまたいだ完全な
  ロールアップ。選択可能なコスト範囲(7d / 30d / 90d / 月初来)、チーム、プロジェクト、
  エージェント、モデル、プロバイダ別の支出内訳、印刷可能なレポート表紙を備える;
- **ホーム概要**(`/`) — 意図的により軽量な玄関口。estate の柱(インベントリ、
  ライブセッション、セキュリティ、コンプライアンス、支出ランレート、health/SLA)を
  単一のグリッドにまとめ、それぞれがそのモジュールへのドリルダウンリンクとなる。

ホーム概要は、ダッシュボードの読み取りフック、純粋なロールアップ、タイル
プリミティブを複製するのではなく再利用し、同じテナントスコープのクエリキャッシュを
共有する。そのため玄関口は軽量(クエリが少ない)でありながら、深いビューとの一貫性を
保つ。

## 何を提示するか(そして何を決して計算しないか)

ダッシュボードは 5 つの柱にわたる KPI を先頭に置く — **コスト**(FinOps XI + Models
X)、**使用量**(Inventory I + Sessions II)、**リスク**(Security IX + Red-teaming
XVIII + access map III)、**コンプライアンス**(XIII)、**信頼性**(Health & SLA
XXII)。ロールアップ層は、モジュールがすでに決定したものを数え、合計し、ランク付け
するだけの**純粋関数**の集合である。コストはモジュールの整数単位のままであり、
検出結果の重大度、red-team スコア、コントロールステータス、health 状態はそのまま
渡される。

何の計算も所有しないため、ソースの正直さのシーム(継ぎ目)を洗い流すことができず、
実際にそうしない。`truncated` な集計は下限としてフラグが立ったままになる。プローブを
完了できなかった red-team の実行は**決して**合格としてカウントされない。近似的または
不透明なカバレッジで観測されたアクセスは下限として提示される。コンプライアンスは
**コントロールカバレッジ**として読まれ、決して「準拠」の主張にはならず、常設の
免責事項を保持する。チェックのない health 対象は `unknown` と読まれ、healthy とは
ならない。

## エクスポートとワイヤー

エクスポートは**オンデマンドかつクライアントサイド**である。ダッシュボードは
ブラウザの「PDF として保存」(`window.print()`)を介して画面上のものを印刷する。
印刷専用のレポート表紙(組織、範囲、生成時刻)と常設の免責事項フッターを伴う。これは
RBAC とテナントスコープに対して**構造上**忠実である — レポートはロールが実際に
レンダリングしたセクションしか含むことができない。エクスポートされたドキュメントは、
ダッシュボード自体と同様に、**集約された KPI のみ — ペイロードなし、シークレットなし**
を運ぶ。最小データは、ワイヤーを越えるものの特性であり、ビューアの良識についての
約束ではない。

## アクチュエーション

モジュール XXI は**アクチュエーション表面を持たない**([モジュールカタログ](/ja/reference/modules/overview/)
では `—`)。これはモジュールがすでに提供する読み取りエンドポイントの上のプレゼン
テーション層であり、いかなる書き込みも発行せず、何も発火せず、何もディスパッチしない。

:::caution[正直な制約]
- **スケジュール配信されるレポートはない。** カタログの設計意図にはスケジュール
  された、エクスポート可能なレポートが含まれる。今日出荷されているのは**オンデマンドの
  クライアントサイド PDF 印刷のみ**である。サーバーサイドのレポーティング
  エンドポイントも、定期スケジュールも、メール配信もない — レポートが自動的に届くことを
  期待してはならない。
- **そのソースが正直である分だけしか正直でない。** すべてのカバレッジギャップ、
  切り詰め、保留中の帰属、免責事項は、基盤となるモジュールから来ており、滑らかに
  整えられるのではなく表示される。低い数値は低リスクを意味する*こともあれば*、
  限定的なカバレッジを意味することもある。各柱はそのモジュールの制約とともに読むこと
  (例: access-map のカバレッジ層)。
- **RBAC はすべての柱をゲートする。** ソースを読めないロールはその KPI を決して
  見ず、印刷もできない。許可されたソースを持たない読者は、捏造されたダッシュボードでは
  なく、正直な空の状態を見る。
- **時点的、単一ソース。** リスク、コンプライアンス、信頼性は現在状態のスナップ
  ショットである。選択された範囲にまたがるのはコストのみである。このビューはこの
  control plane 自身のデータのロールアップであり、外部の BI ツールではない。
:::
