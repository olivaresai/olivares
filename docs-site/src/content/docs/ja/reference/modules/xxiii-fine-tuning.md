自社モデルの物語 — **会社が自ら訓練またはホストするモデル**の統治 — は二つの半分に
分かれ、計画中のまま残っているのはそのうち一つだけです。

**統治する側の半分は今日出荷されています**。それが
[モジュール XXIII — モデルオペレーション](/ja/reference/modules/xxiii-model-operations/)です:
バージョン管理された**自社モデルのレジストリ**(`hosted`、`fine_tuned`、`imported`)、
署名済みモデルの**アドミッション**ゲート、**データセットとファインチューニングジョブの
リネージ記録**、デプロイ時に enforce-signed を再チェックする統治された
**ローカル推論デプロイメント記録**(vLLM、Ollama、llama.cpp、その他)、そして台帳に
アンカーされた封印を備えた **AIBOM / モデルカード**生成。エンティティとエンドポイントは
宣言済みで、ベータのモジュールルート(`/v1/m/models/owned-models`、
`/v1/m/models/model-versions`、`/v1/m/models/finetune-jobs`、
`/v1/m/models/inference-deployments`、`/v1/m/models/aiboms` など)で提供されています —
[モジュールルートリファレンス](/reference/api-beta/)を参照してください。

このページが扱うのは、**計画中であり意図的にまだ構築されていない、実行する側の半分**です:
プラットフォーム自身がその作業を*実行する*ことです。

## 今日出荷されているもの(別ページ)

自社モデルの統治は実在し、
[モデルオペレーション](/ja/reference/modules/xxiii-model-operations/)のページに
文書化されています:

- 不変のバージョンを持つ**自社モデルのレジストリ** — ファインチューニング済みまたは
  セルフホストのモデルが、管理されないエンドポイントではなく、統治された第一級の
  エンティティになります;
- **リネージ記録としてのファインチューニングジョブ** — 外部で実行された訓練作業と、
  各ジョブが生み出したモデルバージョンのインベントリ;
- **統治された記録としてのローカル推論デプロイメント** — あなたが運用するサービング
  ランタイムを、アドミッション強制(`require_signed`)と監査の下に置きます。

## 計画中のまま残っているもの

- **ファインチューニングジョブの実行。** 出荷済みモジュールは、他所で実行された
  ファインチューニング作業の状態とリネージを記録します。プラットフォームは訓練ジョブを
  開始・キャンセル・実行することは決してなく、重みやデータセットの内容も保存しません。
  プラットフォームからファインチューニングを*実行する*パイプラインは計画中の作業です。
- **ローカル推論の提供。** デプロイメントはオペレーターが運用するランタイムの統治された
  記録です。プラットフォーム自身は推論をホストも提供もしません。ファーストパーティの
  ローカル推論サービングは計画中の作業です。

この実行する側の半分については、ジョブスキーマ、スケジューラ契約、サービングランタイム
契約は一切宣言されておらず、このページも意図的に何も発明しません。

## なぜ出荷ではなく計画なのか

このプラットフォームは、どの能力も残りを再設計せずに取り付けられるように構築されている
ため、実行は出荷済みの統治面の上に後から追加できます。明示的なプロダクト判断により
v1 の**後**に置かれました:最初のリリースの優先事項は、組織がすでに動かしている
モデルとエージェントを統治することであり、訓練/サービングの実行はその中核価値を
v1 の労力を競うほどには変えないからです。

構築されるとき、その自然な継ぎ目はすでに出荷されています:実行されたファインチューニングは
[モデルオペレーション](/ja/reference/modules/xxiii-model-operations/)のレジストリにモデル
**バージョン**を生み、外部で生成されたアーティファクトと同じ署名済みモデルの
**アドミッション**ゲートを通ります。ベンダースタックのポリシーは
[モデルとプロバイダーの管理](/ja/reference/modules/x-models/)に留まります。

:::caution[誠実な制約]
- **統治面は出荷済み、実行面は未出荷です。** このページを、レジストリ・アドミッション・
  リネージ記録・デプロイメント統治・AIBOM 証跡の否定として読まないでください — それらは
  存在し、[モデルオペレーション](/ja/reference/modules/xxiii-model-operations/)に
  文書化されています。
- **今日、実行面は存在しません。** 出荷済みバイナリには訓練パイプラインも、
  ファインチューニングジョブのスケジューラも、ファーストパーティの推論サービングもなく、
  それらのためのエンティティ・エンドポイント・イベントは宣言されていません — 拒否する
  インターフェースすらありません。
- **ここにあるものは日付や深さの約束ではありません。** 上記のスコープは計画された方向性
  です。ジョブスキーマとランタイム契約は構築時に設計されます。捏造するのではなく、
  意図的に未指定のままにしています。
:::
