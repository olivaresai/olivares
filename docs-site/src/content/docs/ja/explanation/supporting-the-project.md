Olivares AI は**オープンコア**であり、この分離はマーケティングの仕掛けではありません。
完全なガバナンスプラットフォームは AGPL-3.0-only で、コミュニティコアは最も多く使われる
ことを意図した部分です。どのビルドに何が含まれるかは、[オープンコアと
ライセンス](/ja/explanation/open-core-and-licensing/) を参照してください。

この仕組みには資金が必要です。何がその費用を支えているのかを率直に述べる価値があります。

## 現在、開発を支えているもの

加算的な `enterprise/` ラインの**商用サブスクリプション**です。組織がこれらのモジュールを
必要とする場合、その購入が、他の全員が無料で運用する AGPL コアの資金になります。何も
支払わない人も含まれます。

独立した寄付プログラムは運用されておらず、このサイトのどのページもそのようなプログラムへ
はリンクしていません。変更されればこのページで明記します。それまでは、実際には使えない
経路を案内しません。

## 費用をかけずに支援する方法

いずれも一般的な方法ですが、自らサーバーを運用するエンジニアを対象とした pre-1.0 の
プロジェクトにとって本当に役立つものです。

- **使って、壊れる点を報告してください。** バージョン、コマンド、出力を添えた不具合報告は、
  スター一つより価値があります。製品はベータであり、そのことも明記しています。
- **ドキュメントを修正してください。** ページに書かれた内容が自分の環境では誤りだと分かった
  場合、それはドキュメントの不具合です。ぜひ報告してください。
- **AGPL の下でコードを提供してください。** コアはオープンであり、貢献方法はこのリポジトリの
  通常の方法です。

## スポンサーシップで得られないもの

後で寄付プログラムが始まっても、優先サポート、待ち行列の順番、何を作るかへの影響力は
得られません。サポートの約束は商用サブスクリプションに属し、そこでは文書化され、履行を
求められます。この二つを分けておくことが重要です。静かに支払えば課題の待ち行列で上に
上がれるプロジェクトでは、支払わない多数派が二級扱いになります。コミュニティコアは最も
多く使われる部分であるべきです。
