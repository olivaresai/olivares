このページは、Olivares AI のウェブサイト、README、ドキュメント全体で使われる**あらゆる市場統計の唯一の真実の源（single source of truth）**です。これが存在するのは、AI ガバナンス市場が、語り継がれる過程で帰属が歪められた数字であふれているからであり — そして購買担当者のアナリストはそれを確認するからです。私たちは、裏づけられない数字を引用するくらいなら、歯切れのよい一文を失うほうを選びます。

:::note[帰属のルール]
私たちは**一次情報源のみ**を引用し、それを正確に名指し、情報源が述べるとおりに数値を引用します。帰属を落としたブログを通して数字を**ロンダリング**することはせず、どの購買担当者も追跡できない集約統計（「フォーチュン 100 の 70% が…」）を**積み上げる**こともしません。所見が**予備的または査読を経ていない**場合は、同じ行でそう述べます。これは製品自身が証拠を扱う方法を反映しています。[帰属信頼度](/ja/reference/glossary/#attributionconfidence)は第一級のフィールドであり、設計段階の証拠しか持たないコントロールは `satisfied` ではなく `by_design` を報告します。
:::

## 私たちが依拠する定性的証拠

これらは百分率ではありません。*なぜこのカテゴリが存在するか*を枠づける、名前を挙げて引用できる情報源からの立場です。

- **Bessemer Venture Partners**（*Atlas —「Securing AI Agents: the defining cybersecurity challenge of 2026」*）: エージェントの挙動への進行中・外科的な介入は**「市場が最も未発達であり、最も明確なインフラ機会が存在する場所」**であり、**「ほとんどの企業は自社環境で稼働するエージェントの正確なインベントリを持っていない」**。これは私たちの[アクセスマップ](/ja/explanation/)が埋めるギャップの、外部からの言明です。
- **Anthropic**（Claude Code のサンドボックス化と Managed Agents に関するエンジニアリング投稿）: セルフホストのサンドボックスは実行を顧客が制御するインフラへ移しますが、Anthropic は**監査ログ、ポリシー／RBAC、マルチホストのオーケストレーション、トラフィック検査を顧客に割り当てます**。その委譲された責任こそ、Olivares AI が埋める継ぎ目です — [コントロールタワーとの比較](/ja/explanation/positioning/vs-control-towers/)を参照。

## 調査シグナル（方向性 — 外部引用の前に検証すること）

独立系およびコミュニティの調査は、一貫して同じ形を報告します。エージェントは、組織がそれをインベントリ化したり帰属させたりできるよりも速く増殖している、というものです。私たちは以下の具体的な百分率を、名前を挙げた調査から合成した**方向性のある文脈**として扱います。これらは上記の検証済み一次情報のセットには**含まれず**、いかなる外部利用の前にも元の調査票に照らして再確認すべきです。

- Cloud Security Alliance／Token Security（n≈418）、Protiviti、Optro の各調査は、さまざまに次を報告しています。組織の大きな割合が自社環境に**未知／管理外のエージェント**を抱えていること、**リアルタイムのインベントリ**を維持しているのは少数派にとどまること、過去 1 年で**エージェント関連のインシデント**を経験した組織が多数派であること、そして**エージェントのアクションを人間やシステムまでさかのぼって追跡**できるのは少数派にとどまること。

それらの調査が総体として示す論点こそ、私たちが公に主張する唯一のものです。**組織は自らのエージェントを把握できなくなっており、それらのエージェントが何をするかを帰属させることができない。** これは、私たちの製品がそのユーザーにとって偽となるよう作られている主張であり — このサイトのすべてのポジショニングページの誠実な核心です。

## 私たちが意図的に**主張しない**こと

- 顧客数、ロゴの壁、「N 社の企業に信頼されている」といったものはなし — 製品は 1.0 前かつローンチ前です（[誠実さと限界](/ja/start/honesty-and-limits/)を参照）。
- 保有していない認証や証明はなし（SOC 2、ISO 27001/42001 は**準備状態（readiness）**であって証明書ではありません — ソースに同梱される信頼・調達パッケージを参照）。
- でっち上げのベンチマーク、スループットの主張、精度の数字はなし。容量の数字は、再現可能なベンチマークハーネスから、ハードウェアの来歴（provenance）とともにのみ得られます。
