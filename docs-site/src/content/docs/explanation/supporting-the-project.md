Olivares AI is **open core**, and the split is not a marketing device: the complete
governance platform is AGPL-3.0-only and the community core is the part meant to be
used most. See [Open core & licensing](/explanation/open-core-and-licensing/) for what
is in which build.

That arrangement has to be paid for by something, so it is worth saying plainly what
pays for it.

## What funds the work today

The **commercial subscription** for the additive `enterprise/` line. If your
organisation needs those modules, buying them is what funds the AGPL core everyone
else runs for free — including the people who never pay anything.

There is no separate donation programme in operation, and no page here links to one.
When that changes this page will say so; until then it does not offer a route that
cannot be walked.

## Ways to support it that cost nothing

These are ordinary, and they are genuinely the useful ones for a pre-1.0 project
aimed at engineers running their own servers:

- **Run it and report what breaks.** A defect report with the version, the command
  and the output is worth more than a star. The product is beta and says so.
- **Correct the documentation.** If a page told you something that turned out to be
  false on your machine, that is a defect in the docs and we want it back.
- **Contribute code under the AGPL.** The core is open; the contribution path is the
  normal one for the repository.

## What sponsorship does not buy

If a donation programme opens later, it will not buy priority support, a place in the
queue, or influence over what gets built. Support commitments belong to the
commercial subscription, where they are written down and can be held to. Keeping
those two things apart is the point: a project where paying quietly moves you up the
issue queue is one where the unpaid majority is second class, and the community core
is meant to be the part that is used most.
