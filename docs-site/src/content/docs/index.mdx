## What is this?

Olivares AI runs AI tools such as Claude Code, Codex and Grok Build with shared
sessions, resource access, permissions, policies, budgets and audit evidence.
The binary includes the console and runs on your own infrastructure.
The access map compares permitted access with observed reads and writes.

Olivares AI has no mandatory telemetry. Your configuration selects model API
calls, SIEM and webhook outputs, and any external embedding provider.
Some capabilities are partial or planned; check their documented limits.
