Установка в изолированной среде требует Enterprise. Сценарии развёртывания и полное руководство входят в дистрибутив Enterprise. Community и Business могут проверить пакет автономного обновления без установки:

```bash
olivares upgrade --bundle ./release-bundle --check
```
