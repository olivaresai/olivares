Платный эффект должен **зарезервировать** оценку расхода до выполнения.
Плоскость управления затем **фиксирует** измеренную стоимость или
**освобождает** удержание.

## Как выглядит отказ

Жёсткий потолок (`action=block`) отвечает **HTTP 402**. Мягкий
(`action=throttle`) отвечает **HTTP 429**. Тело называет действие, бюджет и
недостающий запас. Этот эндпоинт требует права записи бюджетов и
отвечает администратору. Прокси вывода никогда не повторяет эту причину:
лимит отказывает с `budget limit reached`, посадочный — с `spend limit reached`,
без имени бюджета и без суммы.

```bash
olivares finops admission reserve --data @reserve.json -o json
```

## Недоступное хранилище (по умолчанию отказ)

Если хранилище бюджетов нельзя прочитать, допуск **отказывает**. Устойчивая
причина: `budget store unreachable (deny-closed)`. HTTP **503**. Также
пишется строка аудита `finops.admission.denied`. Поза по умолчанию — **deny**.

## Как читать сверку

```bash
olivares finops admission reconciliation -o json
```

`drift` истинен при истекших незафиксированных резервах. `reconciliation`
только читает и ничего не меняет; `reconcile` — это работа: она подметает такие
резервы, требует право записи бюджетов и публикует нахождение
`finops_reservation_drift`. Это поза, а не тихая перепись расхода.
