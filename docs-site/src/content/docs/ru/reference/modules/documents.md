---
title: Документы
description: Локальное преобразование в Markdown с MarkItDown; исходные файлы сохранены, без доступа к сети.
---

Прикрепите PDF, DOCX, PPTX, XLSX, HTML, CSV, JSON, XML, EPUB или ZIP к сеансу, загрузите его в «Мои файлы» или укажите путь внутри папки сеанса через `@path`. Для пробелов используйте `@"path with spaces.pdf"`. Microsoft MarkItDown выполняет локальное преобразование; агент получает Markdown как недоверенное содержимое документа. Изображения по-прежнему передаются как изображения.

Исходный файл сохраняется, а Markdown создаётся рядом без замены существующих файлов. Модуль «Документы» включён в новых установках; его можно отключить в «Настройки > Модули». При отключённом модуле или отсутствии конвертера новые преобразования отклоняются с явной ошибкой.

`olivares files convert report.pdf` выводит путь к `report.pdf.md`; `--json` возвращает `{"path":"..."}`. Коды завершения: 0 — успех, 1 — ошибка преобразования, 2 — неверные аргументы. Существующий Markdown не заменяется.

Конвертер не имеет доступа к сети, плагинам и учётным данным провайдеров. Он получает только байты документа через stdin и требует Linux Landlock ABI 3 или новее. Ограничения: по 32 MiB на ввод и вывод, 30 секунд общего времени, 25 секунд CPU и 768 MiB виртуальной памяти. Для вложений сохраняется предел 3,75 MiB. Серверные ISO и образы Docker содержат зависимости с фиксированными хешами; во время преобразования пакеты не устанавливаются.
