title: "Управляемая публикация Git"
description: "Отправка коммитов, создание pull request и слияние через одобренные привязки Git-хоста с текущей авторизацией и сохранением результатов."
---

Модуль gitpublish предоставляет управляемую публикацию в GitHub, GitLab и на простые git-ремоуты (только push). Он входит в Community.

Каждое действие требует одобренной цели, привязок репозитория и учётных данных, а также текущей авторизации. Без нужных привязок, исполняемого файла Git или полномочий публикация отклоняется. Регистрация модуля сама по себе не делает репозиторий готовым к публикации.

Пространство имён API — `/v1/m/gitpublish`. Оно предоставляет цели, намерения push, создания pull request и слияния, сверку и наблюдения.

Push может указать запуск сеанса (`session_run`). Тогда Olivares перед публикацией получает коммит из папки этого запуска в серверный репозиторий, только по локальному файловому протоколу. Запуск должен принадлежать рабочему пространству цели; запрос никогда не указывает путь.

Неопределённый удалённый результат не разрешает повторную попытку. Запросы, наблюдения и подтверждения учитываются отдельно. Уже отправленная удалённая операция может совпасть с последующим локальным отзывом полномочий.
