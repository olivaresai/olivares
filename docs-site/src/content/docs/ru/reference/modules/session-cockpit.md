Двоичный файл Community регистрирует дескриптор доступности для пространства
имён API `session-cockpit`. В этом пространстве имён сейчас **нет обработчиков**
и **нет интерактивного кокпита**. Запросы под `/v1/m/session-cockpit` получают
**404 из-за отсутствия**. Дескриптор не входит в 30 продуктовых модулей
каталога.

## Текущая доступность

| Поверхность | Community (этот артефакт) |
|---|---|
| Пространство имён API | `session-cockpit` (`/v1/m/session-cockpit`) |
| Дескриптор | `olivares.session-cockpit` `0.1.0` — заголовок `Session cockpit (availability)` |
| Зарегистрированные маршруты / обработчики | нет |
| Интерактивный кокпит | нет |
| Объявленное разрешение | `session-cockpit:availability:read` (объявлено, не привязано к маршруту) |
| Жизненный цикл | пустой (`Init` / `Start` / `Stop` ничего не делают) |

404 в этом пространстве имён — ожидаемый ответ Community. Это не означает, что
плоскость управления установилась с ошибкой.

## Как диагностировать отсутствие

Проверьте, что поставляемые поверхности сессий по-прежнему работают:

1. Маршруты модуля живых сессий в пространстве имён `sessions` —
   [Живая эксплуатация и сессии](/ru/reference/modules/ii-sessions/).
2. Консоль **Sessions** (`/sessions`), **Claude Code** (`/agentops`) и
   **Work** (`/work`) — [справочник консоли](/ru/reference/console/).
3. Жизненный цикл официальных CLI в следующем разделе.

Если они отвечают, а `/v1/m/session-cockpit` даёт 404, дескриптор соответствует
этому артефакту.

## Открытые возможности

Установка, запуск, наблюдение и управление официальными CLI остаются в
открытом продукте Community:

- [Живая эксплуатация и сессии](/ru/reference/modules/ii-sessions/) — живые
  сессии агентов, временные шкалы, профили провайдера и `live_ref`.
- [Управлять сеансом провайдера](/ru/how-to/operate-provider-sessions/) —
  запуск Claude, Codex или Grok под закреплённым официальным двоичным файлом.
- [Запуск Claude Code с Olivares](/ru/how-to/run-claude-code-with-olivares/) —
  совместное развёртывание AgentOps для официальных сессий `claude`.
- Руководства по connector и PEP-hook (наблюдать/управлять, не запускать сессию):
  [Claude Code](/ru/how-to/integrations/claude-code/),
  [Codex](/ru/how-to/integrations/codex/),
  [Grok Build](/ru/how-to/integrations/grok/).
- [Запись привилегированных сессий](/ru/reference/modules/recording/)
- [Идентичность, разрешения и управление](/ru/reference/modules/vi-governance/)
