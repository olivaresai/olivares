title: "在隔离网络（air-gapped）站点中上手"
description: >-
  在一个断网的网络上搭建 control plane：将一个经过验证的产物带过隔离边界（静态二进制，或用于集群的已签名 bundle），
  离线验证它、安装，并在零出站的情况下到达首个价值。
sidebar:
  order: 4
---

隔离环境安装需要 Enterprise。部署脚本和完整安装指南随 Enterprise 发行版提供。Community 和 Business 可以验证离线更新包，但不能安装：

```bash
olivares upgrade --bundle ./release-bundle --check
```
