Olivares AI 是**开放内核**，这种划分并非营销手段：完整的治理平台采用
AGPL-3.0-only，社区核心则是希望被最广泛使用的部分。请参阅[开放核心与许可](/zh/explanation/open-core-and-licensing/)，
了解各构建中包含哪些内容。

这套安排必须由某种来源支付，因此有必要坦率说明如今是谁在为它提供资金。

## 如今为开发工作提供资金的来源

附加 `enterprise/` 产品线的**商业订阅**。如果你的组织需要这些模块，购买它们就是在为
其他所有人都可免费运行的 AGPL 核心提供资金，其中也包括从不支付任何费用的人。

目前没有独立的捐赠计划在运作，此处也没有页面链接到这样的计划。情况改变时，本页会
说明；在此之前，它不会提供一条实际上无法走通的途径。

## 无需花费的支持方式

这些都是寻常做法，但对于面向自行运行服务器的工程师、尚未到 1.0 的项目而言，它们确实
很有用：

- **运行它，并报告哪里出了问题。** 一份包含版本、命令和输出的缺陷报告，比一颗星更有
  价值。产品处于 beta 阶段，并且明确说明了这一点。
- **更正文档。** 如果某个页面告诉你的内容后来在你的机器上被证实是错误的，那就是文档
  缺陷；我们希望你把它反馈回来。
- **在 AGPL 下贡献代码。** 核心是开放的；贡献路径就是此仓库通常采用的方式。

## 赞助不能买到的东西

即使日后开放捐赠计划，它也不能买到优先支持、队列中的位置，或对构建内容的影响力。
支持承诺属于商业订阅；它们会被写明，也可以据此追责。将这两件事分开正是关键：一个
悄悄付费就能让人排到 issue 队列前面的项目，会把未付费的大多数变成二等用户，而社区
核心本应是被最广泛使用的部分。
