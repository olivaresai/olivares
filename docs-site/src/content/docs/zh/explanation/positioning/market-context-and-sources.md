本页是整个 Olivares AI 网站、README 与文档中所用**每一项市场统计数据的唯一
事实来源**。它之所以存在，是因为 AI 治理市场充斥着在转述中被歪曲了归属的
数字 —— 而买家的分析师会去核查。我们宁愿失去一句有力的措辞，也不引用一个
我们无法为之背书的数字。

:::note[归属规则]
我们**仅引用一手来源**，准确指明其名称，并按来源所述引用该数字。我们**不**
通过一篇丢弃了归属的博客来"洗白"某个数字，也**不**堆砌买家无从追溯的聚合
统计（"财富 100 强中有 70%……"）。在某项发现属于**初步或未经同行评审**时，
我们在同一行说明。这映照了产品本身对待证据的方式：
[归属置信度](/zh/reference/glossary/#attribution归因置信度)是一等字段，仅有
设计阶段证据的控制项报告为 `by_design`，绝不报告为 `satisfied`。
:::

## 我们所依赖的定性证据

这些不是百分比；它们是来自具名、可引用来源的立场，用以阐明*该品类为何存在*。

- **Bessemer Venture Partners**（*Atlas —— "保护 AI 智能体：2026 年决定性的
  网络安全挑战"*）：对智能体行为进行在途的、外科手术式的干预，是**"市场最不
  成熟、也是最清晰的基础设施机会所在之处"**，并且**"多数企业并不拥有一份对其
  环境中运行的智能体的精确清单。"** 这是对我们的[访问图](/zh/explanation/)所
  弥合的缺口的外部表述。
- **Anthropic**（关于 Claude Code 沙箱与托管智能体的工程博文）：自托管沙箱将
  执行迁移到客户掌控的基础设施中，但 Anthropic **将审计日志记录、策略/RBAC、
  多主机编排与流量检查指派给客户**。那份被委派的责任正是 Olivares AI 所填补的
  接缝 —— 参见[对比控制塔](/zh/explanation/positioning/vs-control-towers/)。

## 调查信号（方向性 —— 对外引用前请核实）

独立与社区调查一致地报告出相同的图景：智能体扩散的速度快于组织清点或归属它们
的速度。我们将下列具体百分比视为综合自具名调查的**方向性背景**；它们**不**
属于上文我们经核实的一手数据集，在任何对外使用前应对照原始调查工具重新核查。

- Cloud Security Alliance / Token Security（n≈418）、Protiviti 与 Optro 的
  调查分别报告：很大一部分组织在其环境中存在**未知/未受管的智能体**，只有
  少数组织维护**实时清单**，多数组织在前一年经历过**与智能体相关的事件**，且
  只有少数组织能将**一项智能体动作追溯回某个人或系统**。

这些调查在总体上所表达的，正是我们公开主张的唯一一点：**组织正在失去对其
智能体的追踪能力，且无法归属这些智能体所做之事。** 这是一项我们的产品旨在为
其用户证伪的主张 —— 也是此处每一个定位页面诚实的核心。

## 我们刻意**不**做的主张

- 没有客户数量、没有徽标墙、没有"受 N 家企业信赖" —— 该产品处于 1.0 之前且
  尚未发布（参见[诚实与限度](/zh/start/honesty-and-limits/)）。
- 没有我们并不持有的认证或存证（SOC 2、ISO 27001/42001 是**就绪度
  （readiness）**，而非证书 —— 参见随源码一同发布的信任与采购资料包）。
- 没有编造的基准测试、吞吐量主张或精度数字。容量数字仅来自可复现的基准测试
  装置，并附有硬件来源信息。
