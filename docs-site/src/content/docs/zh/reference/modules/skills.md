Skills（`modules/skills`、`olivares.skills`）是 32 个模块之一。它拥有**不可变的
技能目录**及其**固定分配**：技能包只安装一次，逐条对照其清单 digest 校验，并作为
不可变修订发布——此后绝不在原地修改。目标（代理、组、工作区）可以使用什么，由一条
把包修订固定下来的**分配**决定，而每一次固定都会写入审计账本
（`skills.assignment.pin`）。

## 它提供什么

- **目录。** 安装在 `/v1/m/skills/packs` 下的包，每个不可变修订都记录其清单
  digest；退役一个仍被分配或被已记录对话使用的包会被拒绝，而不是静默级联删除。
- **内置目录。** 一组随引擎附带的 upstream 技能包，按 commit 与归档 digest 固定
  （`builtin/PIN.json`），安装时的校验与上传归档完全一致。安装时不执行其中任何
  内容。
- **分配。** `GET/POST /v1/m/skills/assignments` 与
  `PUT/DELETE /v1/m/skills/assignments/{id}` 把修订固定到目标（存在活动工作区时
  按其限定）。同名但内容不同的两个已分配技能会在会话启动前被拒绝，因此每次启动
  都是确定性的。
- **Git 导入。** 一个操作员范围的导入器可以在固定策略之下从 Git 源获取技能包；
  导入会作为又一条不可变修订落入目录，而不是引擎读取的活检出。

## 表面与权限

模块的路由位于其 beta 命名空间（`/v1/m/skills/…`），记录在
[模块路由参考](/reference/api-beta/)中，并渲染为控制台的 Skills 视图。读取需要
read 权限；安装包或修订需要 write；退役需要 admin；分配需要 assign 权限。会话只
通过已记录的分配解析其技能——磁盘上发生变化的文件夹，绝不会改变一次已经固定的
启动将要运行的内容。

:::caution[诚实的边界]
- **自 26.10.1<!-- release-fixed --> 版本之后新增。** 官方 26.10.1<!-- release-fixed --> 二进制不含此模块；它随下一个版本
  发布，本页描述的是当前集成线上存在的模块。
- **目录只治理，不执行。** 安装、固定与导入绝不运行技能代码——执行仍由消费固定
  修订的工具与会话承担。
:::
