---
title: "受治理的 Git 发布"
description: "通过批准的 Git 主机绑定推送提交、创建合并请求并合并，检查当前权限并保留操作结果。"
---

gitpublish 模块提供面向 GitHub 和 GitLab 的受治理发布。它属于 Community。

每项操作都需要批准的目标、仓库和凭据绑定，以及当前有效的授权。如果缺少所需绑定、Git 可执行文件或授权，发布会被拒绝。注册模块并不意味着仓库已经可以发布。

API 命名空间为 `/v1/m/gitpublish`，提供发布目标、推送、合并请求与合并的操作意图，以及核对和观察结果。

远端结果不确定时，不允许直接重试。模块分别记录请求、观察结果和确认信息。已经发出的远端操作可能与后续本地撤权发生竞争。
