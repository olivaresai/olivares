# Olivares AI documentation (docs.olivares.ai): robots policy
#
# Same decision as olivares.ai (2026-10-17): public content is open to
# search crawlers, answer engines AND the training crawlers of the major
# assistants. Assistants describe Olivares AI correctly only if they can read
# it, so /llms.txt and /llms-full.txt are published for them and nothing on this
# site is withheld from a crawler that follows robots.txt.
#
# Two groups, one decision each:
#
#   1. Search, answer and training crawlers of the major assistants: nothing is
#      disallowed.
#   2. Crawlers that ignore robots rules or resell what they fetch: refused for
#      the whole site.
#
# A user-agent that has its own group reads ONLY that group. Anything not named
# here falls to the catch-all and may fetch everything.
#
# The legal pages (privacy, terms, imprint) are hosted on olivares.ai, not here;
# their exclusion from AI training is in that site's robots.txt.
#
# Without this file Cloudflare answers with its own content-signals text, which
# has no User-agent, Allow, Disallow or Sitemap directive (measured 2026-09-01).
# scripts/check-robots.mjs checks dist/robots.txt, the tree deployed from public/.
#
# Sources for the agent names: developers.openai.com/api/docs/bots (GPTBot,
# OAI-SearchBot, ChatGPT-User); support.claude.com article 8896518, 2026-04-07
# (ClaudeBot, Claude-SearchBot, Claude-User); google-common-crawlers, 2026-04-23
# (Google-Extended does not affect Search or AI Overviews).
