# Olivares AI documentation (docs.olivares.ai): robots policy
#
# Before this file was added, a check on 2026-09-01 found that /robots.txt
# returned HTTP 200 with 1248 bytes and 24 lines, but no User-agent, Allow,
# Disallow, or Sitemap directives. Cloudflare supplied its content-signals file
# because the origin had no robots.txt.
#
# The site's sitemap (2156 URLs at that check) was not advertised, and the
# main site's training-crawler restrictions did not apply to this subdomain.
# This file applies the project's crawler policy to the documentation site.
# The crawler list and order match the main site.
#
# A check of https://olivares.ai/robots.txt before this file was added confirmed
# that Cloudflare served the repository's bytes without a content-signals preamble
# when the origin supplied robots.txt.
# scripts/check-robots.mjs checks dist/, the tree deployed from public/.
# A crawler with its own group uses that group instead of the default group.

# Default: allow search engines, answer engines, and user-initiated AI requests.

# Allow AI training by Anthropic / Claude.
# Legal pages live at olivares.ai/privacy, /terms, and /imprint; their crawler
# restrictions apply on that site, which hosts them.
# Source: support.claude.com article 8896518, 2026-04-07.
