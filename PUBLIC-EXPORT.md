# About this tree

This repository is the public, curated export of the Olivares AI control plane.
The product is complete here: every shipped module builds and tests from this
tree alone.

Two directory families that exist only in the private development tree are
deliberately not part of the export: the commercial fulfilment tooling
(`commercial/`) and the hosted-cloud control plane (`cloud/`). They are the
proprietary server-side siblings of this open-core product — see LICENSING.md.
Build and test legs that live in those directories detect this file and report
NOT APPLICABLE, visibly, rather than failing or passing silently.

This file is also that detector's marker: it is generated by the export and does
not exist in the development tree. If you delete it, those legs fail with an
explanation instead of guessing which tree they are running in.
