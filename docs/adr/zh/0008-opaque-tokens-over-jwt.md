# ADR-0008: 第一方认证采用不透明的服务端令牌，而非 JWT

- **Status:** accepted
- **Date:** 2026-06
- **Deciders:** Olivares AI (confirmed by adversarial review)
- **References:** API/authz/audit contract (§2, decision §13.2)

## 背景与问题陈述

必须选定第一方认证机制。最初的范围提到了“sessions/JWT”。对于一款安全产品而言，
持有者凭据（bearer credential）的失效模式——吊销、携带机密的声明（claim）、解析库风险——
极为关键。

## 决策驱动因素

- 即时吊销。
- 令牌内部不携带任何机密。
- 最小化密码学解析攻击面；默认安全。

## 考虑过的方案

- **不透明的服务端令牌**（一个随机机密，以哈希形式存储，在服务端查找）。
- 为第一方会话使用 **JWT**。

## 决策结果

选定方案：第一方认证采用**不透明的服务端令牌**。令牌按用途加前缀
（`olvs_` 表示会话，`olvk_` 表示 API key）；服务器只存储一个公开的选择器（selector）
和该机密的 SHA-256，并以常量时间比较。JWT 被限定在 SSO/联邦接缝（seam）中，
而不用于第一方会话。

### 后果

- **优点：** 令牌可吊销、不携带任何机密，也无需对攻击者提供的声明进行密码学解析；默认安全。
- **缺点 / 权衡：** 验证需要一次服务端查找（对控制平面而言可以接受）。
- **中性：** 在协议要求之处，联邦仍然使用 JWT。

## 为何否决其他方案

- **为第一方会话使用 JWT** —— 在过期之前难以吊销，往往会携带声明，并且增加了解析/验证的
  攻击面，而在此处毫无收益。
