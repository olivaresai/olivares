# ADR-0006: Внутрипроцессная шина событий по умолчанию, не зависящая от транспорта для NATS

- **Status:** accepted
- **Date:** 2026-06
- **Deciders:** Olivares AI
- **References:** SDK/runtime/event-bus contract; stack design

## Контекст и постановка проблемы

Коннекторы переносят наблюдения на внутреннюю шину событий; модули и выходные коннекторы
подписываются по типу. Единый бинарный файл должен работать без брокера сообщений, и при этом
развёртывание на нескольких хостах требует распределённой шины.

## Факторы, влияющие на решение

- Отсутствие зависимости от брокера в варианте по умолчанию с единым бинарным файлом.
- Путь к распределённой шине, который не вынуждает подписчиков что-либо менять.

## Рассмотренные варианты

- **Внутрипроцессные каналы Go по умолчанию, за не зависящим от транспорта интерфейсом `Bus`**,
  который может заменить распределённая реализация (NATS).
- **Брокер (NATS) с самого начала.**

## Принятое решение

Выбранный вариант: **внутрипроцессная шина на каналах Go как вариант по умолчанию в v1**, при этом
интерфейс `Bus` **не предоставляет канал**, так что реализацию на **NATS** можно подставить для
развёртываний на нескольких хостах **без изменения ни одного подписчика**. Доставка
асинхронная и at-least-once (как минимум один раз); потребители выполняют дедупликацию по временной метке естественного ключа.

> **Изменено ADR-0017 (2026-06-12):** «at-least-once» в предыдущем предложении
> было неверным как описание доставки ШИНЫ — реализация и контракт S02 §4
> предполагают at-most-once (как максимум один раз) (ошибки обработчика логируются, события в очереди отбрасываются при закрытии);
> at-least-once применяется к повторной эмиссии на уровне источника (повторные запуски `Gather`), что и
> дедуплицируют потребители. ADR-0017 фиксирует поставленный бэкенд NATS: внутрипроцессное
> локальное распределение (fan-out) без изменений + мост NoEcho, межузловая доставка at-most-once, без JetStream в v1.

### Последствия

- **Хорошо:** единому бинарному файлу не нужен брокер; распределённый путь подключается без переделок.
- **Плохо / компромиссы:** семантика at-least-once перекладывает дедупликацию на потребителей.
- **Нейтрально:** NATS опционален и нужен только для распределённой топологии.

## Почему альтернативы были отклонены

- **Брокер с самого начала** — добавляет внешнюю зависимость к каждой установке, перечёркивая
  цель единого бинарного файла / air-gap (изолированной от сети среды) ради ценности, которая нужна только распределённой топологии.
