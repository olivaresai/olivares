# Supporters

Olivares AI is AGPL-3.0 and self-hosted. **The core is free and stays free** — it is never
feature-capped from within, there is no seat cap in the engine, there is no remote kill switch,
licence validation is offline (Ed25519), and the engine makes no licence call. One command does
reach a vendor endpoint: `olivares upgrade`, which asks where the new version is — and
`--endpoint` points it anywhere you like.

This page thanks the people and companies who fund the work anyway.

> **Sponsorship is not a support contract and buys no priority.** How questions and bug reports are
> handled is in [`SUPPORT.md`](SUPPORT.md); commercial terms and the optional add-ons are in
> [`LICENSING.md`](LICENSING.md). Keeping those two separate is deliberate: a project that lets
> sponsorship buy queue position stops being predictable for everyone who does not pay.

## How this page is maintained

Names appear here **only if the sponsor asked for it**. GitHub Sponsors offers a private option and it
is honoured: an unlisted sponsor is not an omission.

There is no automation behind this file today, and saying so is the point — an empty section is an
empty section, not a script that failed quietly. When there is enough traffic to justify generating
it, the generator lands with a gate that proves it ran.

**To sponsor:** the **Sponsor** button on this repository, or
